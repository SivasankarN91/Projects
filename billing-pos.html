Tax & billing

Editable on purpose. GST slabs change — check the current rates against CBIC guidance rather than trusting a default.

Backup — read this

Everything is stored in this browser only. Clearing browsing data, or a browser reinstall, will delete it. Download a backup regularly and keep it somewhere else. Backups restore the whole shop — products, bills and stock.

Limits worth knowing

One device, one counter. Data lives in this browser and cannot be shared between two machines. Use one device for billing.

e-Invoice and e-Way bills are not included. Those apply above the turnover threshold and need a live connection to the government portal. This app is built for shops below that threshold.

Best served from a folder or web address rather than opened straight from a downloaded file — browsers treat file-opened pages inconsistently for storage.
